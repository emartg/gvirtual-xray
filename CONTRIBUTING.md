# Contributing to gVirtualXray

Contributions are welcomed. Open a [pull-request](https://sourceforge.net/p/gvirtualxray/gitroot/ci/master/tree/) or a create [ticket](https://sourceforge.net/p/gvirtualxray/tickets/).

By submitting a pull request or a patch, you
- ensure that you have the right to license your contribution to the gVirtualXray project owners and the community,
- agree that your contributions are licensed under the [gVirtualXray license](LICENSE), and 
- agree to future changes to the licensing.

# Coding standards

All C++ code must adhere to [Google C++ Style Guide](https://google.github.io/styleguide/cppguide.html) with the following
exception:

* Exceptions are permitted.

All documentation must adhere to the [Google Developer Documentation Style Guide](https://developers.google.com/style) with the following
exception:

* The use of British English is favoured.

Thanks for contributing!

# Code of conduct
This project adheres to the [Contributor Covenant][CODE_OF_CONDUCT.md]. By participating, you are expected to honor this code.
